صور مرجعية للاستحمام — حكاية بيتنا

تم تقسيم لوحة الاستحمام إلى صور منفصلة داخل هذا المجلد، مع الاحتفاظ باللوحة الأصلية باسم layan_bathing_storyboard_full.png.

الملفات مرجع بصري ثابت وليست إطارات أنميشن متتابعة متطابقة؛ لذلك لا تستخدمها مباشرة كأنميشن تلقائي. يمكن ربط كل صورة بمشهد أو حالة منفصلة، أو رسم إطارات متناسقة لاحقًا لتحريك الشخصية بسلاسة.

الصور مصممة مع بخار وتغطية بصرية. ملف 19_steam_controls يعرض فكرة واجهة التحكم بالبخار، وهو مرجع صورة وليس زرًا وظيفيًا بحد ذاته.
