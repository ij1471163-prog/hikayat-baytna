# المشاهد التفاعلية (فيديو يتفاعل معه اللاعب)

مشهد يظهر كفيديو، واللاعب يلمس ويضغط مطوّلًا ويمسح ويسحب، والفيديو يرد بمقطع ثاني مع كلام وعدادات.
المحرك داخل اللعبة نفسها (`ivg/ivg_engine.gd`)، يشتغل على الـ APK بدون متصفح. الصورة تنبعج تحت الإصبع وتتموّج لما تفكه.

## كيف ترفع مشهد
1. سوِّ مجلد بهذا الشكل وارفعه على GitHub (Add file ← Upload files):

```
incoming/interactive/<الشخصية>/<اسم_المشهد>/
    scene.json
    idle.mp4
    happy.mp4
    ...كل المقاطع اللي تذكرها في scene.json
```

2. `<الشخصية>` من هذي: `layan` `nora` `sara` `hind` `maysoon` `salma`
3. الأداة تحوّل المقاطع لـ `.ogv` وتفحص `scene.json` (مقطع ناقص، `play` يشير لمقطع غير موجود...) وتركّب المشهد وتبني APK.
   لو فيه خطأ يطلع في تقرير الـ Action وما يتركّب شي.
4. في اللعبة: كلّم الشخصية ← **لقاء تفاعلي**.

مثال جاهز للنسخ: `incoming/interactive/_example/scene.json` (ما يتحول، هذا مجرد نموذج).

## أهم أجزاء scene.json
| الحقل | وش يسوي |
|---|---|
| `start` | اسم أول مقطع |
| `vars` / `meters` | المتغيرات (مزاج، ثقة...) والعدادات اللي تطلع فوق |
| `clips` | المقاطع. كل مقطع فيه: |
| ↳ `src` | ملف أو قائمة ملفات (يختار منها عشوائي) |
| ↳ `loop` | يعيد نفسه (للمقطع الهادي idle) |
| ↳ `then` | وش يشتغل بعده |
| ↳ `inherit` | ياخذ مناطق اللمس من مقطع ثاني (عشان تقدر تلمس وهو يرد) |
| ↳ `hotspots` | أماكن تنلمس: دائرة `{x,y,r}` أو مستطيل `{x,y,w,h}` أو `poly`، بنسب من 0 إلى 1 |
| ↳ `on` | حركات على كامل الشاشة |
| ↳ `pause` | يوقف الفيديو ويسأل اللاعب (اختيارات + عدّاد وقت) |
| ↳ `qte` | حركة بوقت محدد (امسكه!) |
| ↳ `events` | شي يصير في ثانية معيّنة (`at`) |

**الحركات:** `tap` `double` `hold` `swipe-left` `swipe-right` `swipe-up` `swipe-down` `rub` (مسح رايح جاي) `drag`

**الأوامر (`do`):** `play` `add` `set` `say` `if/then/else` `random` `wait` `toast` `fx` (`pulse` أو `shake`) `choices` `resume` `save` `stop`

**الشروط:** `"mood >= 60 && (trust > 2 || !angry)"` (تدعم أسماء عربية)

## ربط المشهد بالعلاقات والرصيد
أضف `game` في scene.json، وبعد ما يخلص المشهد تتحول التغيّرات لتأثير في اللعبة:

```json
"game": {
  "max": 8,
  "fx": {"energy": -3},
  "rewards": [
    {"var": "mood",  "per": 0.1, "stat": "relationship"},
    {"var": "trust", "per": 2,   "stat": "rel"}
  ]
}
```
- `per`: كم يتحول من كل نقطة تغيّر في المتغير (mood +30 × 0.1 = +3)
- `stat`: `relationship` علاقة ليان، `rel` علاقة نفس الشخصية، أو `money` / `energy` / `house_cleanliness` / `laundry`
- `max`: أقصى تأثير لكل مكافأة (يمنع الاستغلال)

## نصايح
- المقاطع كلها بنفس الأبعاد (16:9 أفضل للعبة) ونفس مكان الشخصية، عشان الانتقال يطلع سلس.
- مقطع `idle` لازم يكون `loop: true` وفيه كل مناطق اللمس؛ مقاطع ردة الفعل تكتب `then: "idle"` و`inherit: "idle"`.
- `"debug": true` في scene.json يرسم مناطق اللمس فوق الفيديو أثناء التجربة.
- ما تعرف أماكن الدوائر؟ افتح محرر الويب (وضع `#edit`) في ملف «موتشي التفاعلي»، ارسم المناطق بإصبعك وانسخ الـ JSON.
- المقاطع اللي تنكتب فيها `.mp4` أو `.mov` في JSON تتحول تلقائيًا لـ `.ogv`.

## مشهد تفاعلي بدون فيديو (صور فقط)

تقدر تبني التفاعل الحين بصور اللعبة نفسها، وبعدين تبدّل الصور بفيديوهات وقت ما تجهز. التفاعل (لمس، ضغط مطوّل، سحب، كومبو، اختيارات، عدادات) نفسه بالضبط.

- `src` يقبل صورة (`png/jpg/webp`) أو مسار داخل اللعبة مثل `res://assets/sprites/layan/01_pink_home_pajamas.png`.
- `bg`: خلفية للمشهد كله أو لمقطع معين (مثل `res://assets/backgrounds/...jpg`).
- `duration`: مدة بقاء المقطع الصوري بالثواني قبل ما ينتقل لـ `then` (مثل الفيديو بالضبط، و`pause` و`events` تشتغل بنفس الوقت).
- `breathe: true`: تنفّس خفيف للصورة وهي واقفة.
- الصورة تنبعج تحت الإصبع وتتموّج مثل الفيديو.

### كيف تبدّل لفيديو بعدين
غيّر `src` فقط من الصورة إلى ملف الفيديو (وانسخ الفيديو جنب `scene.json`)، وسمّ الخطوط والـ hotspots كما هي. ما تحتاج تغيّر شي ثاني. تقدر تخلط: مقطع صورة ومقطع فيديو بنفس المشهد.

### المشهد التجريبي
موجود جاهز: كلّم ليان ← لقاء تفاعلي ← «لقاء تجريبي (بدون فيديو)»
(`assets/ivg/layan/demo_images/scene.json`، انسخه كقالب). فيه: لمس الراس، ضغط مطوّل، ٤ لمسات سريعة على الكتف (كومبو)، وسحب لفوق يفتح اختيارات حوار. حط `"debug": true` في scene.json عشان تشوف مناطق اللمس.

## مشهد/فيديو يظهر بحسب شروط (`when`)

حط `when` في `scene.json` وبيطلع المشهد لحاله في اللعبة لما تتحقق الشروط: زر «🎬 اسم المشهد» في الغرفة، مثل «سالفة».
مثال جاهز (فيديو عادي بدون لمس): `_example/video_when.json` (انسخه باسم `scene.json` وحط الفيديو جنبه).

| المفتاح | المعنى |
|---|---|
| `where` | الغرف، مثل `["المطبخ"]` (بدونه أي غرفة بالبيت) |
| `p` | الوقت: 0 صباح، 1 ظهر، 2 مساء، 3 ليل |
| `day` | أقل يوم |
| `rel` | أقل علاقة، مثل `{"ليان": 55}` |
| `who` | مين لازم يكون موجود (الافتراضي: صاحبة المشهد) |
| `need` | مشاهد أو علامات لازم تصير قبله |
| `repeat` | `"daily"` = مرة كل يوم (بدونها مرة وحدة بس) |
| `auto` | `true` = يشتغل أول ما تدخل الغرفة بدون زر |
| `menu` | `true` = يبقى بقائمة «لقاء تفاعلي» بعد |

المشهد اللي فيه `when` ما يطلع في قائمة «لقاء تفاعلي» إلا إذا حطيت `menu: true`.
لو الفيديو بدون لمس، خل المقطع الواحد وانهِه بـ `"on_end": [{"stop": true}]`.
