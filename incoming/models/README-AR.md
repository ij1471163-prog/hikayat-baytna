# مجسمات 3D للشخصيات

ارفع ملف المجسم في مجلد الشخصية (اسم المجلد بالإنجليزي):

| الشخصية | المجلد |
|---|---|
| ليان | `incoming/models/layan/` |
| نورة | `incoming/models/nora/` |
| سارة | `incoming/models/sara/` |
| هند | `incoming/models/hind/` |
| ميسون | `incoming/models/maysoon/` |
| ريم | `incoming/models/reem/` |
| سلمى (الشبح) | `incoming/models/salma/` |

**الصيغة:** `.glb` (الأفضل: كل شي في ملف واحد). `.gltf` يشتغل بشرط ترفع معه ملفاته (`.bin` والصور).

بعد الرفع يتحرك المجسم لحاله لـ `assets/models/` ويبني APK. وفي اللعبة: كلّم الشخصية ← «عرض ٣D».

**في العارض:**
- اسحب بإصبع واحد: تدوير المجسم.
- قرّص بإصبعين (أو عجلة الماوس): تقريب وتبعيد.
- لو المجسم فيه حركات، تظهر أزرار بأسمائها (أول حركة تشتغل لحالها وتتكرر).
- «إعادة الوضع» ترجع الكاميرا للوضع الأول.

**نصايح:**
- أقل من ٥٠ ألف مضلع وتكستشر ٢K أو أقل عشان الجوال ما يبطّأ.
- المجسم لازم يكون مكتسي بالكامل.
- المجسم ينحط في النص ويتكبر لحاله حسب حجمه، فما تحتاج تضبط المقاس.
