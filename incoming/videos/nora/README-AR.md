# فيديوهات نورة

من GitHub: افتح هذا المجلد ← Add file ← Upload files ← اختر الفيديو ← Commit changes.

بعد دقائق يتحول تلقائيًا لصيغة اللعبة، ويبان في اللعبة لما تكلّم نورة (زر «فيديوهات نورة»)،
وينبني لك APK جديد.
