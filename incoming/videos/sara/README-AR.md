# فيديوهات سارة

ارفع هنا أي فيديو لـ سارة (MP4 أو MOV أو WEBM).
من GitHub: افتح هذا المجلد ← Add file ← Upload files ← اختر الفيديو ← Commit changes.

بعد دقائق يتحول تلقائيًا لصيغة اللعبة، ويبان في اللعبة لما تكلّم سارة (زر «فيديوهات سارة»)،
وينبني لك APK جديد.
