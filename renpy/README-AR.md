# حكاية بيتنا (نسخة Ren'Py)

نسخة جديدة مبنية على Ren'Py، فيها الأشياء المكتملة بس.

- المشروع: `renpy/hikayat/`
- القصة: `game/script.rpy` (الأيام والقرارات والنهايات)
- وضع القرب: `game/close.rpy` (المناطق، والعدادات، والكلام)
- الواجهة: `game/screens.rpy`

البناء يصير تلقائياً على GitHub (`.github/workflows/build-renpy.yml`): فحص الأخطاء، صور شاشة، و APK.
